# 派生媒体生成管线

## 目的与边界

生成管线负责执行用户已经明确选择的生成式能力，并从只读来源图片创建新的静态或动态媒体资产。它可以承载 AI 修复、老照片修复、AI 风格重绘、生成式清理等静态生成，也可以承载轻微动态、镜头推进和光影流动三项动态生成；当前真实可用性以 [MVP Spec](../product/mvp-spec.md) 为准。

四张卡片只确定 `CreationTask`。选图后，presentation 以固定顺序展示该任务的 `CreationCapability`，初始没有默认选择。只有用户点击的能力才能进入本管线；图片分析、AI、历史、设备或供应商状态都不能替用户推荐、排序、组合、替换、降级或触发能力。

`creationIntent=apply|motion` 只区分静态与动态页面。能力的内部 `executionKind=staticGenerate|motionGenerate` 决定是否进入本管线，但不构成用户授权。点击具名生成结果授权进入该能力的必要确认，但不自动授权上传、创建任务或扣费；这些动作必须在所选能力的同一确认 sheet 中明确完成。该 sheet 是新的隐私与成本授权，不是第二个“应用”。

生成不要求先创建 `StyleCommit`、先应用风格或先静态导出。它可以是异步、非确定性、远程且有成本，因此不得加入本地 `EditRecipe`、`EditingCore` 或 `RenderPlan`，也不得借用静态撤销历史表达远程任务。

## 来源快照

每个任务绑定不可变 `GenerationSourceSnapshot`，至少包含：

- `SourcePhoto` 的应用自有资产 ID 与内容身份；
- 用户选择的 `CreationTask`、`CreationCapability` 和 `executionKind`；
- 该能力内由用户确认的有界输入，例如 `StyleDefinition`、参考图、蒙版、目标背景或动态方向；
- 可选的专供生成使用的冻结参考渲染及其 SHA-256；
- 请求的结果类型、方向、尺寸、色彩和创建时间；
- 本次上传、费用或权益、取消和删除边界的确认身份。

快照只能从用户当前明确选择并确认的能力创建。它不能从照片分析、文件名、历史选择、屏幕截图、未提交预览或上一份生成结果中推导能力或输入，也不能自动补齐另一个能力。若当前输入不足，系统必须说明缺失并停留在该能力内。

后续换图、改选能力或改变输入不会改写既有快照与产物，只会把旧任务标记为相对当前选择 `stale`；用户可以主动保留或删除它。静态生成可以读取用户确认的 `StyleDefinition`，动态生成只绑定用户明确选择的动态方向，不要求或推导风格。

## Module 与 Interface

`GenerationCoordinator` 是业务层唯一生成 Module。调用方只需要：

- `create`：以已确认来源快照创建一项任务；
- `observe`：读取稳定任务状态和可展示进度；
- `cancel`：请求停止仍可取消的工作；
- `retry`：由用户主动复用同一逻辑意图安全重试；
- `delete`：由用户主动删除本地派生产物并触发约定的远端清理。

供应商请求、鉴权、上传、轮询或回调、下载、格式探针、临时文件和错误映射全部留在 Module 内部。Flutter 的生产 `GenerationProvider` 只连接第一方网关，不持有或直接调用第三方供应商密钥；百度、阿里与火山 Adapter 位于服务端。测试使用可控 Fake；`GeneratedMediaStore` 负责内容寻址的本地派生产物和清理。

## 任务状态

创建远程任务前的 presentation 状态为：

```text
选图片
  → capabilityAwaitingChoice（固定列表、无默认选中）
  → 用户点击一项生成式结果
  → 当前不可用：显示 unavailable，停止
  → 服务可用：直接进入 awaitingConsent（上传、费用、取消与删除说明）
  → 用户确认后创建任务
```

静态云端生成使用 `cloudStaticAwaitingConsent`。轻微动态、镜头推进和光影流动在 iOS 上由选项点击直接本地编码 H.264 MP4，不进入本云端管线，也不展示上传、费用或额度确认。AI 自然动效点击后直接进入该能力的 `awaitingConsent`。不支持某个编码器或云能力的环境只把对应选项进入 `unavailable`，不得自动改走另一执行分支或方向。

任务创建后的队列、运行、失败和待对账状态显示在图片上的紧凑状态中。它们不替换工作区、不遮挡底部选项，也不会因用户查看状态而创建第二个请求。

用户确认后，任务才进入：

```text
queued → running → succeeded
       ↘ failed
       ↘ cancelled
```

- 只有取得当前能力所需的上传、成本与生成确认后才能创建任务。
- `cancel` 是请求而不是成功承诺；若供应商已经进入不可取消阶段，界面必须如实显示。
- `succeeded` 只表示供应商完成且下载产物通过媒体格式、大小、可解码和来源绑定校验。
- 应用重启后只按持久化任务 ID 恢复并对账，不创建新任务。
- 若创建请求已经发出但响应未知，客户端必须先持久化原始请求身份并进入
  `reconciliationRequired`；重启、返回页面或删除项目都不能丢弃这个状态，也不能创建
  第二个云端请求。
- 失败、取消、超时或产物拒绝均不创建或修改 `StyleCommit`，不自动改走其他能力，也不错误扣除权益。

## 幂等、重试与成本

- 每个用户确认的逻辑请求具有稳定 idempotency key；网络恢复不得重复生成或重复计费。
- 超时只结束本地等待，不创建第二个远程任务；系统只用原始请求身份查询原任务终态，
  不重新上传、不重新获取权益，也不再次调用创建接口。
- 对账查询必须同时绑定当前用户、来源快照、能力和原始请求身份；服务端没有证据确认原任务
  未创建前，客户端保持锁定并如实显示“状态待确认”。
- 未知 dispatch 在一个服务端安全窗口内继续锁定同一创建身份和活动并发；窗口结束且仍无供应商
  任务 ID 时，任务转为 `provider_outcome_unknown`，客户端才可解除全局创建锁。原权益预留继续
  `hold` 并计入额度，不能静默 release、settle 或再次 submit；只有活动并发租约被释放，避免一次
  不可对账的旧请求永久禁用所有云端能力。仍在 `pending|running` 且被观察的任务会续租活动并发。
- 失败后只展示原能力的原因和“重试”或返回能力列表；由用户决定下一步。
- 创建前展示会上传什么、预期产物和权益或费用；没有确认不上传、不排队、不扣费。
- 进入任务、选择图片、浏览能力、提交文字/语音/参考图、完成本地操作或查看旧结果都不能自动创建生成任务。

## 隐私与数据生命周期

- 仅上传当前已选能力必需的冻结栅格和有界输入；不上传原始相册路径、无关照片、编辑历史、人脸特征或自由诊断日志。
- 提示词、签名 URL、供应商凭据和图片内容不得进入普通日志、Analytics 或 Crashlytics。
- 本地临时上传文件和失败下载必须可清理；远端保留期和删除能力由 Adapter 明确声明。
- 用户删除项目时，仍被生成任务或派生产物引用的来源必须按引用计数处理；不能留下无主私密文件，也不能误删仍在展示的产物。

## 输出合同

静态生成结果必须是可解码、可保存、可分享且绑定来源快照的受支持图片文件。动态生成结果使用稳定类型 `image_motion`，并至少包含：

- 可播放的受支持动态媒体文件；
- 明确的时长、尺寸、帧率、静音或音频状态；
- 来源快照、请求、供应商模型和产物 SHA-256 的可追溯身份；
- 预览、保存、分享和删除所需的本地状态。

循环方式、输出容器、时长和模型不在架构文档中锁死，由对应能力 Spec、平台能力与质量门决定。本地静态导出始终独立可用。

## 验证合同

- Module 测试覆盖成功、失败、超时、取消、不可取消阶段、重启恢复、重复回调、幂等恢复和产物拒绝。
- 自动化证明进入任一任务时无默认能力，选择能力前无分析后执行、上传、任务或成本；选择后也必须等用户点击主操作并确认才创建任务。
- 隐私测试证明未确认不上传，日志不含路径、提示、签名 URL、凭据、图片或人脸数据。
- 当前集成测试从生产首页进入高清放大和本地动态成功路径，并以公开接缝证明云端能力在用户完成上传与费用确认前不创建任务。网关适配器测试覆盖五项固定能力、私有媒体和幂等身份。
- Profile/Release 真机验证三项动态方向均只能由用户点选，并覆盖后台恢复、播放、分享、删除、存储压力和其他能力不受失败任务影响。
