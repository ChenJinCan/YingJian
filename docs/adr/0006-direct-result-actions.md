# ADR 0006：任务工作区改为结果直达操作

- 状态：Accepted
- 日期：2026-09-03
- 取代范围：取代 [ADR 0005](0005-four-task-home.md) 中任务页进入能力说明或二次应用阶段、换风格主路径使用“官方 / 文字 / 语音 / 参考图 / AI 重绘”的 presentation 决定，以及动态方向需要第二个生成 CTA 的决定。ADR 0005 的四任务身份、用户明确选择、无自动推荐与执行分支隔离继续有效。

## 背景

旧工作区把一次简单选择拆成“选能力 → 看实现说明 → 再点应用”，并用整行导航、底部状态卡和全屏 loading 挤压图片。用户看到的是实现来源和系统自述，而不是想要的结果；云任务状态还会遮住其他选项。

## 决定

1. 工作区去掉整行 `AppBar`，返回和短标题以至少 44 pt 可点区域悬浮在图片上方。
2. 页面不显示“请选择能力”、“系统不会替你选择”、实现参数或第二个应用按钮。固定顺序、无默认选中的具名结果选项已足以表达用户选择边界。
3. 用户点击选项就授权执行该一项：本地能力立即执行；需要用户额外输入的背景、Mask 等能力立即打开该最小输入；云能力立即打开上传和权益必需的确认。云确认是新的隐私/成本授权，不是重复的“应用”。
4. 换风格的新建主路径只固定展示日系、胶片、插画、电影感。日系、胶片和电影感使用固定本地定义；插画使用固定 `illustration-v1` 云端定义。历史文字、语音、参考图和 AI 重绘来源只用于恢复旧项目，不重新出现在主选项栏。
5. 短暂本地执行不跳转 loading 页。云端队列、运行、失败和待对账状态以图片上的紧凑、可恢复状态呈现，底部选项仍可见可点。
6. 连续点击其他选项时，只有最新选择世代的预览、持久化或云端结果可以进入当前画布；已可能到达供应商的任务仍以原请求 ID 对账，不重复创建或扣费。

## 后果

- `CreationCapability` 仍然是持久化的唯一能力授权；“点击即执行”不是系统代选或进入页面后自动执行。
- 本地预览、最终渲染和原子保存属于同一次用户动作；失败时保留上一安全结果。
- 用户可通过直接点击同一选项或另一选项重试/切换，不需要“重新选择能力”中间状态。
- 新建风格扩展必须以可理解的结果名称进入固定选项栏；实现来源不得冒充用户选项。

## 验收

1. 生产导航进入四个任务后，图片是视觉主体，返回/标题悬浮，且没有整行导航占位。
2. 换风格只出现日系、胶片、插画、电影感；三个本地风格一次点击产生结果，插画一次点击进入必要云确认。
3. 优化、清理和动态任务中，每个可执行选项都在点击后直接进入自身结果链，没有说明页或第二个通用 CTA。
4. 云任务的所有非终态和错误状态都不挡住底部选项，也不导致同一创建身份被重复提交。
5. Widget 测试与生产路由 `integration_test` 同时覆盖无默认选择、直达执行、迟到结果、大字号和返回行为。
