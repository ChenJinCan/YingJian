# 本地分析与三推荐基座

## 当前产品行为

导入 1–6 张照片后，项目进入 `analyzing`。应用逐张执行供应商无关的 `PhotoAnalyzer`，把每张状态稳定落为 `ready` 或 `fallback`，全部结束后才进入 `choosingRecommendation`。单项异常被隔离并转为安全回退，不阻断其他照片。

当前生产实现由供应商无关 `PhotoAnalyzer` 选择明确能力：iOS 支持输入调用 Core Image/Vision 小尺寸本地分析并返回 `local-pixels-v1 / ios-core-image-vision-v1`；Android 和其他无原生能力的平台直接使用 `MetadataSafePhotoAnalyzer`。安全回退只绑定内容 SHA-256、方向、尺寸、色彩空间、分析版本和能力版本，不读取或上传像素，也不从文件名、路径或元数据猜测曝光、人物和场景。

`PhotoAnalysisCache` 是 application 层的持久化端口，JSON 实现位于 infrastructure，测试内存实现只存在于 test support。`JsonPhotoAnalysisCache` 将有限分析值写入项目自己的 `analysis/<photo-id>/`，不保存路径、人脸数量、遮罩、自由文本或原始错误。读取同时校验项目 ID、内容身份、方向、尺寸、色彩、分析版本和能力版本；任一变化即 miss。写入先进入同目录唯一暂存路径，暂存结果对读取永远不可见；缓存实现完成所有可等待的校验后，在最终 rename 调用前以同步 generation predicate 取得提交权，再原子替换结果。取消或提交失败只丢弃自己的暂存目录，不删除已提交结果。缓存损坏或读写失败只退化为重新分析，不阻断三推荐。项目/单图删除通过缓存端口清理对应 `analysis/` 范围。

应用进入后台或编辑页销毁时取消当前分析令牌。已经在原生执行的调用可以返回，但未取得最终提交权的旧任务不再拥有项目状态或缓存写入权；已取得提交权的单项先完成其原子提交与状态发布，再让取消作用于后续单项。页面把连续 lifecycle 事件的安全回退保存排入同一串行链；恢复前台、销毁会话、删除项目或分析中移除单张都等待整条链与旧任务收口，再按当前输入重启、执行破坏性变更或释放，避免慢速旧快照复活已删除项目/照片、覆盖新分析和形成无任务等待态。应用被终止在 `running` 时，重启从持久化项目状态重新执行。上述实现仍不是 48 张样片正确性或物理设备性能完成证据。

## 配方目录

`MvpRecipeCatalog` 固定为版本化的 12 套配方，覆盖：

- 自然干净；
- 氛围色彩；
- 质感风格。

目录只包含 `EditRecipe` 已声明的有界参数，没有脚本、动态 Shader、自由提示或云端任务。目录校验要求 12–18 个唯一 ID 和三个产品家族。推荐可以写入已冻结的非几何自然美化安全值；瘦脸、瘦身和其他几何参数始终保持 0，直到用户显式操作。

`LocalRecommendationEngine` 对同一照片身份、分析结果和目录版本始终返回同样的三套不同家族方案。安全回退时只选择 `safeForFallback` 配方，把共享强度限制为 `0.72`，每张补偿标记为 `safeFallbackV1`。分析结果可靠后，曝光和白平衡补偿仍保持在显式小范围内。

## 移动端交互

工作台保留当前照片和组内位置，在工具区之前显示横向三卡选择：选择方案后先完成一次真实渲染，成功才把方案作为单个可撤销事务保存，并进入 `editing`。三卡均标注“本地效果”，没有账号、上传或云端生成前置步骤。

编辑界面不向用户暴露“整组/单张”的范围选择。每个元操作在目录中声明共享语义：色调、色彩和风格自动作用于整组，构图、人像、局部和画质自动作用于当前照片；界面只显示用户要调的能力及当前值。所有入口写入同一编辑状态，并以事务级撤销处理误操作。缩略图用图标和文字同时标记未处理、自动补偿、单张精修、失败或待导出，辅助技术语义包含同样状态。

应用被终止在 `analyzing` 时，可从每张持久化状态与匹配缓存恢复；终止在 `choosingRecommendation` 时，优先读取匹配缓存并确定性重建三卡。选择结果进入既有项目 JSON，重启后直接恢复编辑。

## 仍未验证

- 像素级清晰度、曝光、白平衡、有限场景和人物适用性；
- 48 张授权样片上的危险强度削弱；
- 三方向固定样片预览质量与真人“更省事”指标；
- iOS Profile/Release 物理设备分析性能；Android 验证延期到后续里程碑。

因此当前状态是：三推荐与安全回退 `implemented`，像素分析和质量证据 `validation incomplete`。
