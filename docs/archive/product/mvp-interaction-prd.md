# 映见 MVP 单图交互 PRD

状态：当前目标实施合同

日期：2026-08-28

详细交互、状态、文案和测试合同见 `.scratch/unified-interaction-flow/`。

## 目标

映见 MVP 每次只处理一张照片。用户不需要理解项目分组、整组范围、照片排序、参数事务或批量任务，只完成一条路径：

> 选择一张照片 → 直接编辑 → 即时看到结果 → 撤销或继续 → 导出

文字、语音、快捷建议和手动参数汇入同一套可序列化、可预览、可撤销、可恢复的单图配方。后台照片分析只开放适用能力和替换建议，不阻塞编辑、不自动改变效果。

## 页面结构

稳定页面只有首次引导、首页、编辑器、设置和法律详情。映见不使用 Tab Bar。导入、文字/语音、手动精调、氛围、光照、人物选择、全屏预览和导出都是当前任务内的状态。

当前 MVP 不提供拍照、添加照片、多图计数、照片条、排序、整组范围、批量导出或推荐选择页。

## 首页

### 无草稿

- 品牌与价值主张；
- 一个“选择照片”主按钮；
- 照片默认在本机处理的简短说明；
- 不显示空的最近草稿区域或第二个同义按钮。

### 有草稿

- 最近草稿以一张可点击特色卡展示，提供“继续编辑”；
- 独立提供“选择新照片”；
- 其他草稿列表排除已展示的最近草稿；
- 草稿卡可继续编辑或删除，删除不影响系统相册原图；
- 草稿状态使用“编辑中”“已导出”“有新修改”“需要恢复”“需要更新”。

## 导入

- 系统选择器上限固定为 1。
- 取消选择留在首页，不显示错误，不创建空草稿。
- 选择后首页主操作原位显示“正在准备照片…”。
- 完成应用工作副本、输入校验和项目原子写入后才进入编辑器。
- 导入可以真实取消；失败在首页显示原因、重新选择和必要的系统恢复操作。
- 成功后直接进入中性配方编辑器；后台分析异步开始。

## 编辑器

### 顶部

- 返回、撤销、导出、更多；
- 更多只包含重做、重置所有调整和删除草稿；
- 草稿自动保存，因此输出动作统一叫“导出”。

### 画布

- 照片始终是视觉主体，切换 Dock 不改变画布几何；
- 点按进入全屏，长按临时查看原图；
- 对比按钮可以锁定原图或效果；
- 全屏支持显示/隐藏控制、缩放、拖动和长按原图；
- 首次进入显示一次不阻塞的手势提示。

### 默认 Dock

- 一个统一文字/语音入口“说说想怎么改…”；
- 三个稳定快捷建议槽位；
- 一个“自己调”入口；
- 光照归入氛围或手动工具，不与氛围并列为一级入口。

快捷建议在分析前使用通用内容；分析完成后只替换建议，不增加、删除或移动槽位。

### 即时应用与历史

- 确定性本地调整在校验、预览渲染和原子持久化成功后即时应用；
- 不增加第二次“应用”确认，画布显示结果并提供“已应用 · 撤销”；
- 一次滑杆手势、快捷建议、文字/语音指令或视觉轨道拖动各形成一个事务；
- 未结束手势在切换工具、离开上下文、目标失效或退后台时取消；
- 不允许临时状态进入导出。

### 多人物与工具可用性

- 只有当前意图需要人物目标且存在多个可靠候选时才选择人物；
- 画布编号和底部缩略图明确对应；系统不猜人、不推断身份属性、不转移失效目标；
- 分析中、照片不适用、设备不支持和需要更新使用不同可解释状态；
- 禁止无解释禁用或点击无反应。

## 返回与持久化

返回一次只退出最内层状态：键盘、人物选择/确认、文字语音 Sheet、全屏、当前工具 Dock，最后才离开编辑器。

- 正式应用要求渲染和项目原子写入都成功；
- 离开编辑器前等待最后一次写入；
- 写入失败恢复最后成功状态，并提供“重新保存”或“放弃本次修改并返回”；
- 冷启动只恢复最后成功快照，不恢复任何临时 UI 状态；
- 应用启动落在首页，不自动跳入编辑器。

## 导出

- 点击“导出”按设置中的默认质量直接处理当前照片，不询问范围。
- 导出分为可以真实取消的渲染阶段，以及短暂、不可取消的系统相册写入阶段。
- 取消或失败不破坏草稿；应用被终止后不自动重试。
- 第一次写入前解释“添加照片”权限用途；拒绝后保留草稿并提供系统设置与返回编辑。
- 成功页明确显示“已保存到系统相册”，主操作“完成”，次操作“分享”。
- 分享成功、取消或失败不改变导出成功事实。
- 导出后保留草稿；后续编辑标记“有新修改”；再次导出创建新文件。

## 反馈与无障碍

- 轻量成功使用画布反馈 Pill；
- 可自动恢复失败使用短提示；
- 需要用户操作的问题使用内联错误卡；
- 阻断任务的问题使用专用状态面；
- Bottom Sheet 只承载短任务，Alert Dialog 只承载破坏性确认；
- 同一事件不叠加多个主要反馈表面。

主要点击区域至少 44×44pt，常用操作优先 48pt。2×字体下 Dock 内部滚动且不压缩字号；VoiceOver 必须朗读按钮、滑杆值、目标和进度。Reduce Motion 与 Reduce Transparency 必须尊重系统设置。

## 验收标准

- 用户从首页只需一次照片选择即可进入可操作编辑器。
- 取消选择不创建草稿、不进入空编辑器。
- 最近草稿不重复展示，多份草稿可分别恢复和删除。
- 默认 Dock 只有一个主输入、三个快捷槽位和一个手动入口。
- UI 不存在多图、范围、批量、照片序号、添加照片或推荐选择概念。
- 每次用户意图形成一个可撤销事务。
- 返回逐层收起，持久化失败不静默丢失。
- 多人物目标可辨认且不被自动猜测或转移。
- 导出全程使用单图语言并具备真实取消和权限恢复。
- 2×字体、VoiceOver、Reduce Motion 和 Reduce Transparency 下主流程可完成。
- 正式导航 iOS 集成旅程和已确认的支持测试通过；冻结候选后再完成真机验收。
