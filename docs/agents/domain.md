# Domain docs

映见采用单一领域上下文。

## 探索前读取

- 根目录 `CONTEXT.md`（存在时）。
- `docs/adr/` 中与当前工作相关的 ADR（存在时）。

文件不存在时直接继续。`grill-with-docs` 和 `domain-modeling` 只在词汇或重要决策真正确定后懒创建这些文件。

## 约定

- `CONTEXT.md` 只维护领域词汇及其精确定义，不保存实现方案、计划或临时笔记。
- 所有 Spec、ticket、测试名称和产品讨论优先使用 `CONTEXT.md` 中的规范词汇。
- ADR 只记录难以逆转、缺少背景会令人困惑、且经过真实方案权衡的决定。
- 新结论与现有 ADR 冲突时必须明确指出，不得静默覆盖。
