# 映见 MVP 单图交互 PRD

状态：当前实施合同
日期：2026-08-28

## 目标

映见 MVP 每次只处理一张照片。用户不需要理解项目分组、整组范围、照片排序或批量任务，只完成一条路径：

> 选择一张照片 → 直接调整 → 撤销或重做 → 导出这一张

核心承诺是“让变美更容易”。语音、文字、快捷操作和手动参数都修改同一套可序列化、可预览、可撤销的单图配方。

## 页面结构

稳定页面只有首次引导、首页、编辑器、设置和法律详情。导入、后台能力分析、文字/语音、手动精调、氛围、光照和导出都是当前编辑任务内的状态或覆盖层，不新增一级导航。

首页只提供：

- 选择一张照片开始；
- 继续任意已有单图草稿；
- 在不删除已有草稿的前提下新建单图草稿；
- 进入设置。

## 单图生命周期

```text
empty → importing → editing → exporting → exported
                     ↑              ↓
                     └──失败/取消───┘
```

- 系统选择器的请求上限固定为 1。
- 导入成功后直接进入中性配方编辑器，不增加推荐或范围确认。
- 本地照片分析只在后台识别工具适用性，不改变效果、不阻塞编辑。
- 一个项目只展示和操作一张照片，不提供添加、排序、照片条或切换范围。
- 多个单图项目草稿可同时保存在本地，首页按最近更新时间展示；打开、编辑和删除只作用于选中的草稿。
- 新建草稿不覆盖、不清理已有草稿；只有用户在目标草稿内明确确认删除时，才清理该草稿及其未被其他草稿引用的应用工作副本。
- 旧多图草稿恢复时仅保留原焦点照片；没有焦点时保留第一张。保留该照片当前可见效果，其余应用工作副本清理，系统相册原图不受影响。

## 编辑器合同

- 顶部只保留返回、撤销、导出和低频项目操作。
- 照片画布位置稳定；切换文字、语音、精调、氛围和光照时只替换底部 Dock。
- 不显示 `1/1`、整组/当前照片、照片缩略条、添加照片或批量状态。
- 连续滑杆和轨道在渲染成功后形成一个事务；离散文字或语音结果先预览，再应用或取消。
- 多人物照片只澄清具体人物目标，不引入照片范围选择。
- 原图只读，长按看原图；导出从原图和已应用配方生成一个新文件。

## 导出合同

- 顶部“导出”直接导出当前照片，不再询问“全部/当前”。
- 处理中允许取消；失败后可重试；成功后可分享或完成。
- 文案使用单数对象，不出现“批量、整组、全部照片、未开始项”。
- 预览与导出必须使用相同参数语义，不能覆盖系统相册原图。

## 异常与恢复

- 取消选择：保留原草稿并恢复选择入口。
- 导入失败或超时：显示原因并允许重新选择。
- 后台分析失败：相关工具保持不可用，照片效果不改变。
- 预览失败：恢复上一个安全配方，不写入历史。
- 保存项目失败：保留最后成功状态并明确提示。
- 导出失败或取消：回到可编辑状态并允许重试。

## 验收标准

- 用户从首页只需一次选择即可进入可操作编辑器。
- 已有草稿不阻塞新建；至少两份草稿可同时展示并分别恢复。
- 选择器最多返回一张，项目内没有第二张照片入口。
- UI 中不存在照片条、照片计数、添加照片、整组范围和保存范围选择。
- 语音、文字、手动、氛围、光照、撤销、重做和单图导出可完成。
- 大字号下照片和主操作仍可用；主要触控区域至少 44pt。
- Widget 测试和 iOS Simulator 集成测试通过正式导航验证选择一张、编辑和导出。
