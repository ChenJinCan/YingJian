# 映见单图 MVP Spec

## 产品边界

映见当前版本一次只精修一张照片。多图导入、整组一致性、照片排序、照片条、范围切换和批量导出不属于本阶段能力，也不在界面中保留占位入口。

## 功能切片

1. 从系统相册选择一张受支持照片并创建应用工作副本。
2. 立即以中性配方打开编辑器。
3. 后台分析人像、身体和稳定目标，仅用于开放适用工具。
4. 用户通过文字、语音、快捷操作或手动参数修改同一配方。
5. 每次应用形成一个可撤销、可重做的原子事务。
6. 从只读原图导出当前照片并可分享结果。

## 不包含

- 同一项目中的第二张照片；
- 添加、排序、切换或同步照片；
- 整组/当前照片范围；
- 批量进度、部分成功或仅重试失败项；
- 初始推荐选择页；
- 默认云端上传和生成式图片任务。

## 工程合同

- Flutter 管理 UI、单图项目状态、配方和任务编排。
- 原生层管理高频预览和高清导出；Flutter 不在滑杆期间传输完整图片字节。
- 原图只读；预览和导出复用同一版本化参数语义。
- 所有效果可归零、可撤销、可恢复、可序列化。
- 后台分析是非阻塞能力检测，失败不能改变配方或阻断基础编辑。
- 旧多图快照只用于迁移；恢复后成为单图项目。

## 质量门

- `flutter analyze` 和完整 Flutter 测试通过。
- 正式 iOS Simulator 路径进入生产导航，选择一张照片，执行至少一个主要编辑并完成导出。
- UI 检查加载、空态、错误、取消、大字号和关键交互。
- 最终冻结候选仍需 Profile/Release 和物理设备验收；模拟器不能替代真机证据。
