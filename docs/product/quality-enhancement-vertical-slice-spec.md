# 画质改善纵切 Spec

> 状态：implemented / validation-incomplete；版本：1.0；日期：2026-08-07；首发平台：iOS。

## 用户结果

用户从已有图片进入正式编辑页后，可以一键改善轻度噪点、暗部不可读、低对比灰雾和轻微软化，也可以分别调整去噪、暗光提亮、去灰和细节锐化。所有处理默认本地执行，从只读原图导出，不生成不存在的内容。

## 参数合同

- `noiseReduction`、`lowLightRecovery`、`hazeRemoval`、`detailSharpening` 均为整数 `0...100`。
- `0` 严格关闭对应效果；四项全零与 V5 原管线保持像素语义一致。
- “一键改善画质”只写入冻结的安全推荐值 `28/32/18/16`，不形成隐藏渲染层。
- 四项可独立调整、归零、撤销、重做、项目恢复，并通过 V6 参数合同送入同一预览/导出管线。
- 画质改善属于当前照片的显式修正，不自动同步整组，也不由人像适用性阻断。

## 处理边界

- 去噪降低细碎噪声，保护明显边缘；不承担大面积皮肤磨皮。
- 暗光提亮定向抬升暗部，限制亮部变化；不伪造 HDR。
- 去灰恢复低对比层次，限制对比和饱和增量；不替代局部去雾模型。
- 细节锐化增强已有亮度边缘；不恢复失焦、运动模糊或缺失纹理。
- 超分辨率、生成式细节、人脸生成修复和严重去模糊不属于本纵切。

## 自动正确性门

- V6 严格拒绝未知字段、布尔、非整数、越界值和缺失字段。
- 四项全零与 V5 同输入结果一致。
- 暗光正样片的暗部亮度单调增加，同时亮部变化受限。
- 去灰正样片的低对比分离度增加，但不得产生通道裁剪。
- 去噪正样片的相邻高频亮度差下降，保护边缘子集不得明显变软。
- 细节锐化正样片边缘响应增加，平坦区噪声增量和 halo 受限。
- 纹理预览和最终 JPEG 使用同一 V6 参数与顺序。

## 完成定义

代码、Flutter 行为、iOS 原生正确性、正式导航集成测试与 Profile/Release 构建全部通过后，可标记为工程完成。固定真实照片的同图盲评、物理 iPhone 性能与复杂噪声/暗光视觉检查未通过前，保持 `validation-incomplete`，不得宣称达到竞品画质修复质量。
